# Brief

Send this to the knight you chose. Replace every guidance line (the italic line under each heading) with the real text and keep the six headings as they are.

## Goal
_One sentence: the outcome you need, stated so that it can be checked._

## Context
_Why the work exists and what the receiving knight cannot know: what you already tried or ruled out._

## Inputs
_Everything needed to start: paths, URLs, issue numbers, IDs, data, or the exact text to use. Say where each one lives._

## Constraints
_Limits they must respect: scope, tools or files to leave alone, time, and anything that must not be sent, published or changed._

## Output wanted
_The exact form of the reply: format, length, and where any file or PR goes, such as /data/work/... or a PR URL._

## Done when
_The observable test that the task is finished, such as a command that passes or a list that is complete._
